- 8인 팀 프론트엔드 총괄

- PR 및 리뷰 기준 수립
- 닉네임 변경 후 다른 화면에 즉시 반영되도록 상태 동기화 구현
- Flutter · Riverpod

#### 토닥 | AI 기반 반려동물 비대면 진료 서비스

- 상태 기반 UI와 유효성 검사, 로딩 안내 개선
- SSAFY 웹디자인 트랙 우수팀 및 우수상
- React · TypeScript · Zustand
